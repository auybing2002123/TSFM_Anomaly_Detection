# 数据集、实验结果、架构与创新点

## 1. 使用的数据集

### 1.1 MSDS（Microservice System Dataset）

- 场景：连续时序微服务监控
- 节点规模：5 主机
- 样本数：11,148
- 模态：Metrics + Logs + Traces（三模态）
- 目标任务：每个主机异常检测 + 根因定位

### 1.2 RCAEval RE2-TT（Train Ticket）

- 场景：故障注入微服务系统（Train Ticket）
- 节点规模：68 服务
- 样本数：25,830
- 模态：Metrics + Logs + Traces（三模态）
- 案例：90 个故障案例（5 个根因服务 × 6 种故障 × 3 次重复）
- 目标任务：每个服务异常检测 + 根因定位

## 2. 核心实验结果

### 2.1 最终主结果

| 数据集 | Test F1 | Precision | Recall | Accuracy | Val-Test Gap |
|---|---:|---:|---:|---:|---:|
| **MSDS** | **0.9403** | 90.65% | 97.67% | 99.87% | 0.19% |
| **RE2-TT** | **0.8974** | 89.39% | 90.09% | 99.85% | 1.37% |

结论：在两个不同规模数据集（5 主机 / 68 服务）上都达到不错的 F1，且泛化间隙小。

### 2.2 关键对比结论（MSDS）

- 最佳配置：`lr=1e-4, batch_size=16, abnormal_weight=2.0`
- 冻结 GPT-2（只训 LN+wpe）优于不冻结（不冻结出现明显过拟合）
- LoRA 在 MSDS 上未超过当前最佳无 LoRA 配置

### 2.3 关键对比结论（RCAEval）

- 成功迁移到 68 服务规模 RE2-TT
- Precision/Recall 相对均衡（89.39% / 90.09%）
- 分层划分下保持稳定泛化（Val-Test Gap 1.37%）

## 3. 模型架构图（简略版）

```text
Metrics (B,T,N,Dm) ──> MetricEncoder ──┐
Logs    (B,T,N,Dl) ──> LogEncoder ─────┼─> concat + FusionProj(->768)
Traces  (B,T,N,N,Dt) -> TraceGraphEncoder(GATv2) ─┘
                                             │
                                             ▼
                                 Frozen GPT-2 Backbone (6层)
                                 (每个服务独立时序建模)
                                             │
                           前 T-1 步预测第 T 步，得到预测偏差
                                             │
                                             ▼
                                   Classifier (每服务二分类)
                                             │
                                             ▼
                           输出每个服务异常概率 + 根因排序
```

注：先把三模态信息编码并融合，再用冻结 GPT-2 预测下一时刻，利用“预测偏差”判异常。

## 4. 三个创新点

### 创新点 1：冻结预训练 GPT-2 作为时序异常检测主干

- 将预训练语言模型迁移到微服务时序异常检测
- 采用参数高效策略（冻结主体，仅训练少量参数）
- 在不同规模数据集上保持稳定泛化

### 创新点 2：三模态服务级融合 + 预测偏差检测机制

- 统一建模 Metrics / Logs / Traces 三模态
- Traces 通过图编码器注入服务调用结构
- 通过“预测值 vs 真实值”偏差构造异常信号，而非仅依赖重构误差

### 创新点 3：多层可解释性分析链路

- 根因定位：服务级异常概率排序
- 模态归因：Shapley（精确 3-player）+ 交互效应
- 时序归因：GPT-2 逐步预测偏差 + IG 时间归因
- 特征归因：定位具体指标/日志模板/调用边
