\begin{abstract}
Cloud microservice systems have become the backbone of modern online services, where timely fault diagnosis is critical for maintaining reliability and service availability. However, real-time diagnosis in production environments remains challenging due to three fundamental issues: heterogeneous multimodal monitoring data, stringent latency constraints for online inference, and dynamic workload variations that render static diagnosis pipelines inefficient.
To address these challenges, this paper presents \textbf{ASID}, an \textit{\textbf{A}daptive \textbf{S}parse \textbf{I}nference framework for real-time multimodal fault \textbf{D}iagnosis} in cloud microservice systems. ASID first encodes metrics, logs, and traces through modality-specific lightweight encoders and projects them into a unified temporal representation space. It then employs a predictive backbone to model normal system evolution and extracts anomaly-sensitive residual representations from prediction deviations. To reduce online inference overhead, ASID introduces a context-aware sparse expert routing mechanism that dynamically activates only a small subset of diagnosis experts according to runtime system states. Based on the learned representations, the framework jointly performs anomaly detection, root-cause ranking, and interpretable diagnosis generation.
We implement ASID on a realistic cloud microservice diagnosis platform and evaluate it using representative fault datasets under dynamic workloads. Experimental results show that ASID consistently outperforms state-of-the-art baselines in fault detection and root-cause localization accuracy, while significantly reducing inference latency and computational overhead, demonstrating its practicality for real-time intelligent cloud operations.
\end{abstract}
